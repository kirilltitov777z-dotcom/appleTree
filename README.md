# AppleTree 🍎

Спокойная игра-кликер про яблоневый сад на Kotlin + Jetpack Compose.
Без неона и тёмных кислотных цветов: голубое небо, зелёные холмы, тёплый крем.

## Что есть в игре (v1.0 Light)

- **Сад.** Крупные, хорошо видимые яблоки на дереве. **Задержки нажатия нет** —
  жми как угодно часто. Дерево растёт по уровням, полоска роста и очки всегда
  на виду, анимация и звук/вибрация включаются в настройках.
- **Прокачка стала легче.** Сила сбора, **Удача** (критический урожай ×2),
  Садовник (яблоки без тебя), Удобрение (рост дерева) и Пресс (курс монет).
  Цены снижены, эффект и текущий уровень видны прямо в карточке — после покупки
  цена и зелёная доступность обновляются сразу, без «залипшего» цвета.
- **Яблоки → монеты.** Продажа урожая, буст ×2 на час.
- **Страны.** Своя страна: название, цвет, эмблема. Заявки на вступление,
  лидер принимает или отклоняет, выход и передача лидерства. Внутри страны —
  **чат**: сообщение видно всем участникам.
- **Карта переделана.** 12 регионов на красивой читаемой карте: территория
  закрашивается цветом твоей страны, регионы можно **захватывать и развивать**
  (уровень региона даёт бонус яблок в секунду). Прогресс захвата 0–100 %,
  бонусы видны на карте, топ стран всегда под рукой.
- **Профиль.** Статистика, звук/вибрация, сброс прогресса, адрес сервера.
- **Онлайн-режим (опционально).** Регистрация и вход по сети, общий мир,
  общие страны, заявки, карта и чат. Без сервера игра полностью работает офлайн.

## Сборка APK

```bash
./gradlew :app:assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK 35. Готовый APK также собирается в GitHub Actions
(вкладка **Actions** → артефакт `appleTree-debug`).

## Онлайн через Supabase (основной вариант)

Адрес Supabase и publishable-ключ уже вшиты в приложение, поэтому на экране
входа достаточно включить «Играть по сети» — больше ничего настраивать не надо.

Один раз нужно создать таблицы в базе:

1. Открой <https://supabase.com/dashboard/project/yfcwrdxeihsbggtmemcf/sql/new>
2. Скопируй туда целиком [`supabase/schema.sql`](supabase/schema.sql) и нажми **Run**.
3. Готово: регистрация, страны, заявки, захват регионов и рейтинг станут общими
   для всех игроков.

Схема создаёт таблицы `players`, `countries`, `applications`, `regions`,
12 стартовых регионов и разрешает доступ по publishable-ключу.

## Свой сервер (альтернатива)

Папка [`server/`](server/README.md) — Node.js без зависимостей.
`cd server && npm start`, затем в игре на экране входа включи
«Играть по сети» и укажи адрес сервера. Если адрес не содержит `supabase.co`,
приложение само переключится на свой сервер.
